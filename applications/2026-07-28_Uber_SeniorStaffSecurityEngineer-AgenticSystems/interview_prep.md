# Interview Prep — Uber, Senior Staff Security Engineer (Agentic Systems)

## Likely behavioral questions
1. Tell me about a time you had to set technical direction for a project without a formal management title.
2. Describe a time you had to mentor or upskill less experienced engineers on your team.
3. Walk through a decision where you had to make a call with incomplete information and significant ambiguity.
4. Tell me about a time you drove a cross-functional security initiative (IT, product, or operations) to completion.
5. Describe a time you had to champion an engineering best practice that wasn't yet the team norm.

## Likely technical questions
1. Walk through the Python-based orchestration framework you built across nine SIEM/EDR platforms — how would that architecture change if the target were corporate endpoints (macOS/Windows/Linux) instead of SIEM APIs?
2. How have you approached vulnerability data at scale — walk through ingesting Tenable scan data and building detection content on top of it.
3. How would you use GenAI/LLMs specifically for endpoint security posture management, beyond the triage/detection-generation work you've already done?
4. Describe your IAM implementation experience in AWS and GCP — how would you extend that to organization-wide endpoint access governance?
5. This role explicitly wants someone who can "set organizational-level technical direction." How do you approach influencing technical strategy without direct authority?
6. You haven't owned host-hardening (CIS benchmarks) or an end-to-end patch management process — how would you ramp up on that specifically?

## Questions to ask them
1. What does "own the platform, architecture, and tools" for endpoint security look like day-to-day for this specific team, versus the broader Enterprise Security org?
2. How is technical direction currently set for the endpoint security platform, and what would change with this hire?
3. What's the current state of the next-gen endpoint security platform — greenfield, or an existing system being re-architected?
4. How does this role's scope compare to a Staff-level security engineer role — what's the specific step-up in ownership?
5. What does the path look like for someone strong on vulnerability data/analytics and multi-platform orchestration, but newer to formal endpoint architecture ownership at this scale?

## Salary anchor
Posted range: **$267,000–$297,000/year** base (same across SF/Seattle/Sunnyvale/NYC), plus bonus/equity. Given the real level and scope gap (Senior Staff, organizational technical direction, no formal leadership title held), anchor initial expectations to the lower third of this band, and let the interview process surface whether the actual day-to-day scope is a better match than the title suggests.

## Closing-the-interview script
"I'd love to bring that vulnerability data engineering, multi-platform orchestration, and GenAI automation background to Enterprise Security — what would the first 90 days look like for someone who's led technical direction at the team level, stepping into an organizational-level scope?"
