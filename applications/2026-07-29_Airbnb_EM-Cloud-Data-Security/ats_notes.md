# ATS Coverage — Airbnb, Engineering Manager, Cloud & Data Security

## Coverage summary
Good technical fit, real management-scope gap. Built per Kyle's explicit go-ahead after the fit flag was raised.

## Direct matches
- "Deep understanding of modern cloud security practices across AWS... IAM, network security, secrets management, workload identity" — direct match: confirmed hands-on IAM policy/role implementation in AWS and GCP.
- "Familiarity with securing data platforms and pipelines, including access controls, encryption, and data governance patterns" — direct match: SIEM/Elasticsearch data platform work at Shorepoint (DOE/NNSA), API token/role/permission management across nine SIEM platforms.
- "Strong technical judgment across infrastructure security domains... cloud-native detection and prevention controls" — direct match: 2,300+ detection rules, detection quality metrics, staged rollout practice.
- "Strong partnership skills... embedded security partner rather than an external gatekeeper" — good match: track record working directly with SOC/IR/platform teams as a technical contributor.

## Real gaps (not claimed — noted here only, never in the cover letter)
- **"3+ years of People Management experience leading a team of Security Engineers"** — this is a hard, explicit minimum qualification. Kyle has team-lead/sprint-lead experience directing technical priorities and mentoring engineers, but has never held a formal management title or owned headcount/performance management. This is the single biggest risk in this application — an ATS or recruiter screen keying on "3+ years people management" may screen this out before a human ever reads the resume.
- **Kubernetes/container security depth** — JD wants "Kubernetes, container security" as a domain of strong technical judgment. Kyle has worked within a Kubernetes-orchestrated platform as a user, not as cluster admin or K8s security architect — real exposure, not the depth implied.
- **Infrastructure-as-code** — JD lists this as a domain; Kyle's IaC experience is GitLab CI/CD-centric, not Terraform/CloudFormation ownership.

## Read before applying / interviewing
Salary ($212,000–$265,000) and remote eligibility (US-remote, with occasional office/offsite travel) are both excellent and among the strongest in this pipeline. Be direct in any recruiter screen about the people-management gap early rather than let it surface as a surprise later — Kyle's honest pitch is "extensive technical leadership and mentorship without the formal title," which is a real and defensible story but not the same as what's asked for. Kyle chose to move forward with this application anyway given the strength of the technical/compensation match.
