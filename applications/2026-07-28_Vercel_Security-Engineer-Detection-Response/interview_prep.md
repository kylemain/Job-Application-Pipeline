# Interview Prep — Vercel, Security Engineer, Detection Response

## Likely behavioral questions
1. Tell me about a time you owned corporate security posture end-to-end, not just production detection.
2. Describe supporting a compliance audit (PCI, SOC2, ISO) — or the closest equivalent you've done.
3. Tell me about managing a vendor/tooling relationship for security operations.
4. Describe a time you had to triage and remediate an incident solo, fast.
5. Tell me about improving endpoint security posture across a mixed-OS fleet.
6. Describe navigating shifting priorities in a fast-paced, high-growth environment.
7. Tell me about a time you built visibility into a system that had none.

## Likely technical questions
1. You're a Python engineer — how would you approach ramping on Rust or Go for this role? (Honest gap — have a concrete learning plan ready, not just reassurance.)
2. Walk through how you'd evaluate and stand up a new detection for CorpSec vs. production security.
3. Describe your SIEM engineering and alert-tuning approach in depth.
4. How would you support a PCI or SOC2 audit with limited prior formal GRC experience?
5. Walk through your AWS cloud security background — IAM, network, logging specifics.
6. How do you use SQL for security investigations — give a concrete example.
7. Describe your GitLab CI/CD detection-as-code pipeline and how it would map to GitHub administration.

## Questions to ask them
1. How is the CorpSec vs. production-security split actually divided day to day on this team?
2. What does the compiled-language requirement look like in practice — is it for existing tooling, or new build-out?
3. How is remote pay banding determined relative to the SF-anchored range posted?
4. What's driving the current PCI/SOC2/ISO audit cadence, and how much of this role is audit support vs. engineering?
5. What would the first 90 days look like for someone ramping into this role?

## Salary anchor
Posted SF band: **$208,000–$312,000.** Confirm the actual remote-location band with the recruiter early — even adjusted for location, this should clear the $170K floor comfortably. Anchor to the top third once fit and location banding are both confirmed.

## Closing-the-interview script
"This maps closely to the SIEM and detection-engineering work I've built my career on — my main gap is hands-on production experience in a compiled language rather than Python, which I'd want to be upfront about. How is the team weighing that against the rest of the background?"
